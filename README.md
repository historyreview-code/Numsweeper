# NumSweeper BL v2.5

数字扫雷 · 数量化推理挑战

一个基于数值累计策略的逻辑谜题游戏。在 10×10 网格上摆放 1-100 的不重复数字代替传统地雷，玩家需要找出所有安全格子，同时避开触发爆炸。

## 游戏规则

- 网格中每个格子有一个 1-100 的不重复数字
- 点击格子会**翻开**该格，显示其数值
- 翻开格子的规则：**当前格子数值 + 所有相邻已翻开格子数值之和 > 250 则触发爆炸**（爆炸即游戏结束）
- 目标：安全翻开全部 100 个格子

## 策略提示

游戏内置三层策略引擎，实时辅助决策：

| 阶段 | 策略 | 说明 |
|------|------|------|
| 中央启动 | 优先点击中央 4x4 区域 | 中央格子邻居多，信息增益最大化 |
| 内圈推进 | 扩展至内部 8x8 区域 | 利用已揭示信息推断安全格 |
| 外圈收尾 | 清理边缘区域 | 边缘格子邻居少，需更谨慎计算 |

### 提示系统

悬停任意未翻开格子可查看：
- **安全概率**：当前安全点击的概率（%）
- **污染度**：相邻未翻开的格子数，越多越危险
- **推荐指数**：综合安全概率和污染度的策略评分（0-100）
- 格子边框颜色标记风险等级（低/中/高/极高）
- ✕ 标记表示必爆格子（不可点击）
- ⭐ 高亮标记当前最优选择
- 支持两种策略对比（v2.5 vs Border-Last），可批量模拟（100 次）

## 功能特性

- ✅ Canvas 高性能渲染 — 替代 DOM 网格，渲染仅 1-2ms
- ✅ 实时策略提示 — 安全概率、污染度、推荐指数
- ✅ 最佳移动推荐 — 高亮最优选择、标记必爆格
- ✅ 两种策略对比 — v2.5 vs Border-Last，支持单次对比和批量模拟
- ✅ 难度分阶段 — 中央启动 → 内圈推进 → 外圈收尾
- ✅ 撤回上一步 — 误触可撤回（最多保留 10 步）
- ✅ 通关危险地图 — 通关后高亮显示所有被成功规避的危险单元格
- ✅ 可视化提示栏 — 悬停查看详细策略分析
- ✅ 音效反馈 — 点击/爆炸音效 + 语音播报
- ✅ 烟花庆祝 — 爆炸时触发粒子烟花效果
- ✅ 响应式设计 — 移动端触摸优化

## 技术栈

纯前端单文件应用（HTML + CSS + JavaScript），使用 Canvas 2D 渲染，无外部依赖。

### 性能优化

| 优化项 | 描述 |
|--------|------|
| Canvas 渲染 | 替代 DOM 网格，渲染耗时从 15-25ms 降至 1-2ms |
| 邻居预计算表 | 静态 `NEIGHBORS[10][10]` 查找表，O(1) 访问 |
| rAF 分帧模拟 | 批量策略模拟按帧分割，避免 UI 冻结 |
| CSS contain | 布局约束减少重排传播范围 |
| 移动端适配 | 触控目标 ≥ 38px，`touch-action: manipulation` |
